## 5. Request/Response Transformation Pipeline

```
 USER INPUT (camelCase)              SDK TRANSFORM              API FORMAT (snake_case)
 =======================             =============              ======================

 --- videos.create() ---

 { script }               --->     { input }              --->  POST /v1/generate
 { webhookUrl }           --->     { webhook_url }               Body: JSON
 { webhookSecret }        --->     { webhook_secret }
 { idempotencyKey }       --->     Header: Idempotency-Key
 { options }              --->     { options }

 API Response                       SDK Transform               User Gets
 ============                       =============               =========
 { job_id, status }       --->     { id: job_id }        --->  Video { id, status,
                                                                        url, error }

 --- videos.retrieve() ---

 id (string)              --->     URL param              --->  GET /v1/jobs/{id}/status

 API Response                       SDK Transform               User Gets
 ============                       =============               =========
 { id, status,            --->     { url: video_url,     --->  Video { id, status,
   video_url,                        error: error_message }            url, error }
   error_message }

 --- videos.fromJourney() ---

 { productContext }       --->     { product_context }    --->  POST /v1/videos/from-journey
 { stepDuration }         --->     { step_duration }             Body: JSON
 { avatarPosition }       --->     { avatar_position }
 { tone }                 --->     { tone }
 { screenshots }          --->     { screenshots }
 { descriptions }         --->     { descriptions }
 { productUrl }           --->     { product_url }
 { pages }                --->     { pages }

 API Response                       SDK Transform               User Gets
 ============                       =============               =========
 { success,               --->     { videoPath,           --->  JourneyVideo
   video_path,                       videoUrl,
   video_url,                        durationSeconds,
   duration_seconds,                 fileSizeMb,
   file_size_mb,                     stepsCount,
   cost,                             cost, success,
   steps_count,                      error }
   error_message }
```

## 6. Journey Mode Decision Tree

```
                         videos.fromJourney(params)
                                   |
                    +--------------+--------------+
                    |                             |
             params.screenshots?           params.productUrl?
                    |                             |
               +----+----+                  +-----+-----+
               |         |                  |           |
              YES        NO               YES          NO
               |                           |
        +------+------+            +-------+-------+
        |             |            |               |
  descriptions?    (no desc)    pages?         (url only)
        |             |            |
       YES           NO          YES
        |             |            |
   MODE 1a       MODE 1b      MODE 2
   Screenshots   Screenshots   URL + Pages
   + Desc        Vision AI     Navigation
   (fastest)     analyzes


  MODE 1a: screenshots[] + descriptions[]    --> Server uses provided descriptions
  MODE 1b: screenshots[] (no descriptions)   --> Server uses Vision AI to analyze
  MODE 2:  productUrl + pages[]              --> Server navigates & captures
  MODE 3:  productUrl + mode:'autonomous'    --> AI-driven exploration (planned)

  DEFAULTS APPLIED BY SDK:
  +-------------------+--------------------+
  | stepDuration      | 15 (seconds)       |
  | avatarPosition    | 'bottom-right'     |
  | tone              | 'professional'     |
  +-------------------+--------------------+
```

## 7. Error Handling Flow

```
                     SDK Method Call
                           |
                           v
                   private request()
                           |
                    fetch(url, opts)
                           |
              +------------+------------+
              |                         |
         response.ok              !response.ok
              |                         |
              v                         v
     Parse JSON body           Parse JSON body
              |                         |
     Transform to SDK          throw new VloexError(
     response format             data.detail ||
              |                  data.message ||
              v                  'API request failed',
     Return typed object         response.status
     (Video|JourneyVideo)      )
                                        |
                                        v
                                Caught by user code:
                                try { ... } catch(e) {
                                  e instanceof VloexError
                                  e.statusCode  // HTTP code
                                  e.message     // Error text
                                  e.name        // 'VloexError'
                                }

  +-------+------------------------------+----------------------------+
  | Code  | Meaning                      | Typical User Action        |
  +-------+------------------------------+----------------------------+
  | 400   | Bad request / invalid params | Fix script/parameters      |
  | 401   | Invalid API key              | Check key at dashboard     |
  | 402   | Quota exceeded               | Upgrade plan               |
  | 429   | Rate limit exceeded          | Wait and retry             |
  | 500   | Server error                 | Retry after delay          |
  +-------+------------------------------+----------------------------+
```

```
     |  })                               |                               |
     |---------------------------------->|                               |
     |                                   |  POST /v1/generate            |
     |                                   |  { input, webhook_url,        |
     |                                   |    webhook_secret }           |
     |                                   |------------------------------>|
     |                                   |                               |
     |                                   |   { job_id, status: queued }  |
     |                                   |<------------------------------|
     |    { id, status: queued }         |                               |
     |<----------------------------------|                               |
     |                                   |                               |
     |  (user continues other work)      |     (video processing...)     |
     |                                   |                               |
     |                                   |                               |
  Webhook                               |                          (completed)
  Receiver                               |                               |
  ========                               |                               |
     |                                                                   |
     |            POST https://your-app.com/api/vloex-webhook            |
     |    Headers:                                                       |
     |      X-VLOEX-Signature: sha256={hmac}                             |
     |      X-VLOEX-Timestamp: {unix_ts}                                 |
     |    Body:                                                          |
     |      { event: "video.completed",                                  |
     |        job_id: "...", video_url: "..." }                          |
     |<------------------------------------------------------------------|
     |                                                                   |
     |  Verify signature:                                                |
     |    1. Check |timestamp - now| < 300s                              |
     |    2. message = "{timestamp}.{payload_json}"                      |
     |    3. expected = HMAC-SHA256(secret, message)                     |
     |    4. crypto.timingSafeEqual(expected, provided)                  |
     |                                                                   |
     |  Return 200 OK                                                    |
     |------------------------------------------------------------------>|
     |                                                                   |
```

## 12. Module Export & Import Patterns

```
  src/index.ts EXPORTS:
  +=======================================================+
  |                                                       |
  |  default export: vloex(apiKey, baseUrl?) => Vloex     |
  |                  (factory function)                   |
  |                                                       |
  |  named exports:                                       |
  |    - Vloex           (class)                          |
  |    - Video           (interface, re-export from types)|
  |    - GenerateParams  (interface, re-export from types)|
  |    - VloexError      (class, re-export from types)    |
  |    - JourneyParams   (interface, re-export from types)|
  |    - JourneyVideo    (interface, re-export from types)|
  |                                                       |
  +=======================================================+

  CONSUMER IMPORT PATTERNS:
  +=======================================================+
  |                                                       |
  |  // Pattern 1: Factory function (recommended)         |
  |  const vloex = require('@vloex/sdk')('vs_live_...');  |
  |                                                       |
  |  // Pattern 2: Default import + call                  |
  |  const init = require('@vloex/sdk').default;          |
  |  const vloex = init('vs_live_...');                   |
  |                                                       |
  |  // Pattern 3: Class constructor                      |
  |  const { Vloex } = require('@vloex/sdk');             |
  |  const vloex = new Vloex('vs_live_...');              |
  |                                                       |
  |  // Pattern 4: ES Module / TypeScript                 |
  |  import vloex from '@vloex/sdk';                      |
  |  import { Vloex, VloexError } from '@vloex/sdk';      |
  |                                                       |
```

## 16. Security Model

```
  +===========================================================+
  |                    SECURITY LAYERS                         |
  +===========================================================+
  |                                                           |
  |  LAYER 1: API Authentication                              |
  |  +-----------------------------------------------------+ |
  |  | Authorization: Bearer vs_live_...                    | |
  |  | Set on every request in private request() method     | |
  |  | Validated server-side, returns 401 if invalid        | |
  |  +-----------------------------------------------------+ |
  |                                                           |
  |  LAYER 2: Idempotency Protection                          |
  |  +-----------------------------------------------------+ |
  |  | Header: Idempotency-Key: {uuid}                     | |
  |  | Prevents duplicate charges on network retry          | |
  |  | Set via params.idempotencyKey on videos.create()     | |
  |  +-----------------------------------------------------+ |
  |                                                           |
  |  LAYER 3: Webhook HMAC Signature Verification             |
  |  +-----------------------------------------------------+ |
  |  | Algorithm: HMAC-SHA256                               | |
  |  | Header: X-VLOEX-Signature: sha256={hex_digest}       | |
  |  | Header: X-VLOEX-Timestamp: {unix_seconds}            | |
  |  |                                                     | |
  |  | Verification steps:                                 | |
  |  |   1. |timestamp - now| must be < 300s (anti-replay) | |
  |  |   2. message = "{timestamp}.{payload_json}"         | |
  |  |   3. expected = HMAC-SHA256(secret, message)        | |
  |  |   4. crypto.timingSafeEqual(expected, provided)     | |
  |  |      (constant-time comparison, anti-timing-attack) | |
  |  +-----------------------------------------------------+ |
  |                                                           |
  |  LAYER 4: Transport Security                              |
  |  +-----------------------------------------------------+ |
  |  | All API calls over HTTPS                             | |
  |  | Base URL: https://api.vloex.com                      | |
  |  +-----------------------------------------------------+ |
  |                                                           |
  +===========================================================+
```
